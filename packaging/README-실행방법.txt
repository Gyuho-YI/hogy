Cockpit — 개인용 매매 계획 프로그램 (Windows)
=================================================

[처음 실행]
1. 이 폴더(Cockpit)를 원하는 위치에 둡니다. 예: C:\Cockpit
   ※ 바탕화면/다운로드 폴더도 되지만, OneDrive 동기화 폴더는 피하세요.
2. Cockpit.exe 더블클릭
   - "Windows의 PC 보호" 창이 뜨면: [추가 정보] → [실행]
     (서명되지 않은 개인 프로그램이라 표시되는 경고입니다)
   - 방화벽 창이 뜨면 [취소] 해도 됩니다(이 PC 안에서만 사용).
3. 브라우저가 자동으로 열리면 로그인 비밀번호를 정합니다(아이디: owner).
4. [설정] → 계좌 금액 입력 → 저장 → [지금 실행]
   - 국내: 장 마감 후 18시 이후 실행 / 해외: 미국 장 마감 후 실행
   - 수 분 걸립니다. 완료되면 [국내]/[해외] 화면에 매매 계획이 나타납니다.

[매일 사용]
- 프로그램이 켜져 있으면 자동 실행: 국내 평일 18:35, 해외 화~토 07:10
- 화면 다시 열기: Cockpit.exe 를 한 번 더 실행하거나 http://localhost:18080
- 끄기: [설정] → [프로그램 종료]

[윈도우 시작 시 자동 실행(선택)]
- Win+R → shell:startup → 열린 폴더에 Cockpit.exe 의 '바로 가기'를 넣습니다.

[데이터 위치 / 백업 / 업데이트]
- 데이터: C:\Users\<사용자>\Cockpit  (output, data, logs)
- 백업: 위 폴더의 data 를 복사해 두면 매매일지가 보존됩니다.
- 새 버전: 이 프로그램 폴더만 통째로 교체하면 됩니다(데이터 유지).

[문제가 생기면]
- C:\Users\<사용자>\Cockpit\logs 의 cockpit.log / batch-kr.log 내용을 확인하세요.

본 프로그램은 매매 '추천'만 제공하며 주문을 실행하지 않습니다. 투자 판단과 책임은 본인에게 있습니다.
